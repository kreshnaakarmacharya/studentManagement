# Student Management System

A full-stack student management web application built with **Java 17**, **Spring Boot 3.5.4**, and **Thymeleaf**, providing complete CRUD operations for managing student records with academic marks tracking.

## 🎯 Features

### Student Management
- ✅ Add new student records
- ✅ View all students in a list
- ✅ Update student information
- ✅ Delete student records
- ✅ Automatic total marks calculation 

### Student Information Tracked
- Personal details (Name, Email, Address)
- Academic marks (Math, Social Studies)
- Total marks (auto-calculated)

### Web Interface
- ✅ Responsive web UI with Thymeleaf templates
- ✅ Form validation
- ✅ User-friendly navigation
- ✅ Clean, modern design
- ✅ Easy-to-use CRUD interface
